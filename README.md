# virt-top-go

Консольная утилита для мониторинга памяти Linux хоста-гипервизора и гостевых виртуальных машин KVM/QEMU/VBOX. Работает напрямую с Unix-сокетом libvirt через RPC-протокол.

> ⚡ **Vibecoding Disclaimer:**
> Этот проект создан в режиме **вайбкодинга (vibecoding)**.

Домашний проект для того чтобы разобраться как работает память в Linux, используемым как гипервизор с KVM или VirtualBox.
а также прогноз сколько реально свободной памяти можно рассчитывать в работе.

---

## Возможности

- Показывет информацию о памяти уровня хоста
  - Разделение Total, Free, Used, Avail, Cached, Buffers, Shared.
  - Разделение **Disk Swap** (файлы и разделы на накопителях) и **zRAM** (сжатые пулы в оперативной памяти).
  - Считывает реальную физическую статистику сжатия из `/sys/block/zram*/mm_stat` (несжатый объём, занятая RAM, коэффициент сжатия).
  - Отображает состояние **zswap** и дедупликации **KSM (Kernel Samepage Merging)** (эксперементально, требует подтверждения на реальных данных).
  - отображение доступности памяти по каждому физическому NUMA узлу процессора (эксперементально, требует подтверждения на реальных данных).
- Показыват информацию о виртуальных машинах на QEMU/KVM и VirtualBox
  - Показывает информацию о детекте KVM, VirtualBox.
  - Отображает информацию о ВМ как текущего пользователя, так и всех пользователей если запускается с sudo/root.

- Показывает информацию о прогнозах  
  - Расчёт потенциально доступной памяти (**Idle in RSS**). Предполагаем что этот тот объем который хост потенциально может вернуть.
  - Оценка риска переподписки (**Worst-Case Headroom**) отдельно от текущего выделения (`ALLOC_ACT`)(как риск срабатывания OOM-killer на хосте) и от максимума конфигурации (`MAX_LIMIT`)(как запас для динамического расширения (Memory Hotplug)). То есть сколько свободной памяти останется у хоста в худших сценариях.

- Режимы работы
  - **Обычный запуск:** - вывод информации в stdout
  - **Интерактивный режим (`--top`):** - обновление экрана в реальном времени с настраиваемым интервалом (--delay).
  - **Потоковый режим (`--stream`):** - вывод информации в stdout с настраиваемым интервалом (--delay). Режим аналогичен как у virt-top --stream.

- Для получения гостевых метрик `GUEST_AVAIL` и `GUEST_FREE` на виртуальных машинах должны быть установлены гостевые компоненты для virtio или vbox.

## Сборка и запуск

### Быстрый запуск из исходников

```bash
git clone https://github.com/srgkr/virt-top-go.git
cd virt-top-go
go run main
Компиляция статического бинарника
CGO_ENABLED=0 go build -ldflags="-s -w" -o virt-top-go main.go
Запуск
# Разовый вывод текущего состояния
./virt-top-go
или
sudo ./virt-top-go

# Интерактивный режим с обновлением каждые 2 секунды (top)
./virt-top-go --top

# Настройка интервала обновления (например, 5 секунд)
./virt-top-go --top --delay 5

# Потоковый режим с повторным выводом каждые 2 секунды 
./virt-top-go --stream
```
